# RED-011 — PostgreSQL de desenvolvimento

Backlog: P0, S, depende de RED-004. Aceite: “Conexão funcional por variável de ambiente.”

O projeto Supabase REDPRO existente foi reservado exclusivamente para desenvolvimento por autorização do usuário. Nenhum projeto duplicado ou plano pago foi criado. A conexão pelo código foi comprovada via `db:check`, com consulta real, transação de somente leitura confirmada pelo servidor, PostgreSQL 17 e validação TLS de CA/hostname.

O exemplo vazio e a proteção do Git foram ampliados para as variáveis privadas. O arquivo local e a CA não são enviados. A base pública e `/api/health` preservam o comportamento anterior, sem depender desse banco.

Ver [DATABASE.md](DATABASE.md) para configuração, segurança, limites e avisos existentes. Senhas que passaram pelo chat precisam ser trocadas pelo proprietário fora do chat; o código não rotaciona credenciais.

Validação local: 46 testes unitários, formatação, lint, TypeScript, política de ambiente, build de produção e smoke HTTP passaram. A busca dos valores privados atuais nos arquivos candidatos ao Git e nos assets públicos do build retornou zero correspondências, sem imprimir valores. A execução remota de CI e publicação depende do envio e integração autorizados; configuração preparada não substitui a evidência de conexão descrita acima.
