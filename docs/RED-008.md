# RED-008 Logging base e request ID

Backlog: P0, M, depende de RED-001. Aceite: “Requisições têm identificador; logs evitam segredos.”

Entrega: proxy Next.js para gerar IDs e registrar entrada, logger estruturado por lista de campos/valores permitidos e wrapper de conclusão para o handler health. O contrato de health é preservado. Status/duração finais são registrados pelo handler instrumentado; páginas possuem ID e evento de entrada nesta fase.

Testes específicos cobrem privacidade, IDs únicos e concorrentes, propagação no proxy e handler, preservação da resposta, falhas e destino de logs indisponível. O tratamento global de erros fica na RED-009.

Consulte docs/LOGGING.md. Verificações locais, CI e deploy serão registrados no relatório de entrega. Nenhuma credencial ou serviço externo é necessário.

Validação local: proteção de ambiente, formatação, lint, tipos, 18 testes e build passaram. O smoke confirmou IDs válidos e distintos nas quatro rotas. A requisição com marcadores sintéticos confirmou correlação proxy/API e ausência dos marcadores nos logs controlados. CI e publicação ainda dependem do envio autorizado.
